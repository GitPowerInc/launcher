### **`PyLauncher`**

**👋 Bonjour et bienvenue à notre projet, un launcher python compatible avec Windows, Linux et même MacOS\! Celui-ci est présenté sous forme de galerie, dans laquelle vous pouvez y retrouver une variété d’outils, de jeux et même d’illusions d’optiques que nous avons pu réaliser dans le cadre de cette année scolaire\! Ce launcher à été conçu par Maixent Araud, Adrien Lachaize et Victor Gomez Canet.** 

[**Download**](https://github.com/GitPowerInc/launcher/archive/refs/heads/main.zip) **• [Documentation](https://github.com) • [Requirements](https://github.com/GitPowerInc/launcher/blob/main/requirements.txt)**

## **🖥️ Compatibilité**

**Bien que le launcher en lui-même ne nécessite que librairies: os, sys, subprocess qui sont déjà intégrées par défaut avec Python, certains programmes nécessitent installer d’autres librairies:**

* **`Tueur_d_ovni:` \-  Nécessite `pygame>=2.6.1`**  
* **`Chatbot v7.0.0:` \-  Nécessite `tkinterdnd2>=0.4.3 et customtkinter>=5.2.2`**  
* **`Autres:` \-  Nécessite `darkdetect>=0.8.0 et packaging>=24.2`**

## **📥 Installation**

### **Supported Operating Systems**

**PyLauncher est disponible pour Windows, Linux, et macOS.** 

#### **Windows**

##### **Windows Powershell/Command Prompt**

**`cd C:\path\to\script`**  
**`python launcher.py`**

#### **macOS**

##### **Terminal**

**`cd /path/to/script`**  
**`python launcher.py`**

### **Linux**

#### **Vérifier que Gnome Terminal soit installé:**

**`gnome-terminal \--version`**

### 

#### **Installer GNOME Terminal :**

##### **Debian-based distributions (Ubuntu, etc.) :**

**`sudo apt update`**  
**`sudo apt install gnome-terminal`**

##### **Fedora :** 

**`sudo dnf install gnome-terminal`**

##### **Arch-based distributions :** 

**`sudo pacman \-S gnome-terminal`**

##### **Other Linux distributions :** 

Pour d'autres distributions, vous pouvez consulter directement le [GitLab de GNOME Terminal](https://gitlab.gnome.org/GNOME/gnome-terminal/-/wikis/home). Sinon, vous pouvez aussi essayer :

**`sudo yum install gnome-terminal`**

#### **Terminal:**

**`cd /path/to/script`**  
**`python launcher.py`**
